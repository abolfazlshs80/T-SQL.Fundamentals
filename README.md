## مسیر پیشنهادی مطالعه

۱. ابتدا مدل داده و یکپارچگی را مرور کنید.
۲. با ساختار SQL Server و دستورهای پایهٔ `SELECT` آشنا شوید.
۳. اتصال جدول‌ها و تجمیع را تمرین کنید.
۴. سپس CTEها، توابع پنجره‌ای و تغییر امن داده را بخوانید.
۵. در پایان، Viewها، Indexها و ملاحظات زمانی و کارایی را بررسی کنید.
