# مبانی SQL Server

## سلسله‌مراتب مفهومی

- **SQL Server instance**: سرویس اجرایی که مدیریت اتصال‌ها و پایگاه‌های داده را بر عهده دارد.
- **Database**: محدودهٔ اصلی نگهداری اشیا و داده‌های یک سامانه.
- **Schema**: فضای نامی برای دسته‌بندی و مالکیت اشیایی مانند جدول و View.
- **Database object**: جدول، View، تابع، رویهٔ ذخیره‌شده و دیگر اشیای پایگاه داده.

نام کامل یک جدول معمولاً به شکل `schema.object` نوشته می‌شود:

```sql
SELECT EmployeeId, DisplayName
FROM dbo.Employees;
```

پیشوند `dbo` نام Schema است؛ مشخص‌کردن آن کد را روشن‌تر می‌کند و از ابهام نام‌ها می‌کاهد.

## فایل‌های پایگاه داده

SQL Server از فایل‌های داده برای نگهداری ساختار و داده‌ها و از فایل‌های Transaction log برای ثبت تغییرات لازم جهت مدیریت تراکنش و بازیابی استفاده می‌کند. این فایل‌ها نقش یکسان ندارند و نگهداری یا پشتیبان‌گیری از هرکدام باید مطابق برنامهٔ عملیاتی پایگاه داده باشد.

## نکات اجرایی

- بین اتصال به سرور و انتخاب پایگاه دادهٔ هدف تفاوت بگذارید.
- برای اشیای برنامه Schemaهای روشن و باثبات تعریف کنید.
- دسترسی‌ها را در سطح موردنیاز اعطا کنید؛ برای کار روزمره از دسترسی مدیریتی بی‌دلیل استفاده نکنید.
- پیش از اجرای اسکریپت تغییردهنده، پایگاه دادهٔ هدف را صریحاً کنترل کنید.
