# تغییر داده و تراکنش

## دستورهای تغییر داده

- `INSERT` ردیف می‌افزاید.
- `UPDATE` مقدار ستون‌های ردیف‌های انتخاب‌شده را تغییر می‌دهد.
- `DELETE` ردیف‌های انتخاب‌شده را حذف می‌کند.

برای جلوگیری از تغییر ناخواسته، پیش از اجرای `UPDATE` یا `DELETE` شرط را با یک `SELECT` بررسی کنید و مطمئن شوید دامنهٔ آن دقیق است:

```sql
UPDATE dbo.Products
SET Discontinued = 1
WHERE ProductId = 42;
```

هنگام درج، مشخص‌کردن نام ستون‌ها خوانایی و پایداری را بیشتر می‌کند:

```sql
INSERT INTO dbo.Departments (DepartmentId, DepartmentName)
VALUES (7, N'پشتیبانی');
```

## تراکنش‌ها

تراکنش چند تغییر را به یک واحد منطقی تبدیل می‌کند. تغییرها یا همگی ثبت می‌شوند (`COMMIT`) یا در صورت خطا بازگردانده می‌شوند (`ROLLBACK`).

```sql
BEGIN TRANSACTION;

UPDATE dbo.Accounts
SET Balance = Balance - 50
WHERE AccountId = 1;

UPDATE dbo.Accounts
SET Balance = Balance + 50
WHERE AccountId = 2;

COMMIT TRANSACTION;
```

در کد واقعی، بررسی کنید هر دو حساب دقیقاً به تعداد مورد انتظار تغییر کرده باشند و برای مسیر خطا امکان بازگردانی وجود داشته باشد. تراکنش‌ها را کوتاه نگه دارید تا قفل‌ها بی‌دلیل طولانی نشوند.

## پیش از اجرا

1. پایگاه داده و شرط‌ها را بازبینی کنید.
2. برای تغییرهای حساس، نسخهٔ پشتیبان یا راه بازگشت عملیاتی داشته باشید.
3. تعداد ردیف‌های تحت‌تأثیر را بسنجید.
4. تراکنش را با سطح جداسازی و مدیریت خطای مناسب برنامه انتخاب کنید.
