# پرس‌وجوی داده

## ساختار پایهٔ `SELECT`

```sql
SELECT EmployeeId, DisplayName
FROM dbo.Employees
WHERE IsActive = 1
ORDER BY DisplayName;
```

- `SELECT` ستون‌های خروجی را تعیین می‌کند.
- `FROM` منبع داده را مشخص می‌کند.
- `WHERE` ردیف‌ها را پیش از تولید نتیجه فیلتر می‌کند.
- `ORDER BY` ترتیب خروجی را مشخص می‌کند؛ بدون آن ترتیب تضمین‌شده‌ای وجود ندارد.

## فیلترها و NULL

از `AND` و `OR` برای ترکیب شرط‌ها و از پرانتز برای روشن‌کردن اولویت استفاده کنید. برای مقایسه با مقدار تهی از `IS NULL` یا `IS NOT NULL` استفاده می‌شود؛ `= NULL` شرط درستی برای این منظور نیست.

```sql
SELECT OrderId, ShippedAt
FROM dbo.Orders
WHERE ShippedAt IS NULL
  AND CreatedAt >= '20260101';
```

برای ستون‌های متنی، از مقایسهٔ رشته‌ای متناسب با نیاز استفاده کنید؛ رفتار بزرگی و کوچکی حروف و مرتب‌سازی می‌تواند به Collation وابسته باشد.

## محدودکردن نتیجه

در SQL Server می‌توان از `TOP` برای گرفتن تعداد محدودی ردیف استفاده کرد. برای نتیجهٔ قابل پیش‌بینی، آن را همراه با `ORDER BY` به‌کار ببرید:

```sql
SELECT TOP (10) ProductId, UnitPrice
FROM dbo.Products
ORDER BY UnitPrice DESC, ProductId;
```

ستون دوم مرتب‌سازی tie را می‌شکند تا انتخاب ردیف‌ها پایدارتر باشد. در صفحه‌بندی نیز باید ترتیب یکتا و ثابت تعریف شود.

## عادت‌های مفید

- فقط ستون‌های لازم را انتخاب کنید؛ `SELECT *` را برای کد پایدار به‌کار نبرید.
- نام ستون‌ها را در خروجی‌های محاسباتی با Alias روشن کنید.
- شرط‌ها را تا حد امکان روی ستون خام بنویسید تا بهینه‌ساز فرصت استفاده از Index را داشته باشد.
- فیلترها را با داده‌های مرزی، مقادیر تهی و نتیجهٔ خالی آزمایش کنید.
